# Rona Retouch — editor and AI foundation

`/retouch` combines an independent browser editor with the isolated `retouch_backend` service. Existing Upscale UI, model adapters, parameters and processing pipeline are unchanged. The shared server adds only dispatch hooks for `/api/retouch/`.

## Editing

Open one JPEG, PNG or WebP via the file button or drag/drop into the canvas (256 MB, 50 MP limit). Original pixels stay in a decoded image for the lifetime of the page. Ordinary editing stays in the browser; Automatic face analysis in the Retouch menu sends the current edited photo to this computer's loopback server only. Changing files with unexported edits requires confirmation. Closing/reloading with edits invokes the browser's normal leave-page prompt.

Crop is a temporary overlay until Apply. Free, Original, 1:1, 4:3, 3:4, 3:2, 2:3, 16:9, 9:16, 4:5, 5:4, 5:7, 7:5, 2:1, 1:2 and 21:9 supported, with eight resize handles and movable selection. Integer output dimensions may round a fractional ratio by one pixel. Cancel discards the overlay. Rotate and flip are immediate, undoable operations.

Exposure, brightness, contrast and saturation render actual pixels. Slider gestures commit one history step on change; numeric fields also commit on blur. Filters are local canvas colour effects: Original, Natural, Vivid, Warm, Cool, Soft, Portrait, Vintage, Sepia, Mono, Dramatic, Matte, Cinematic, Forest, Fade, Noir, Golden Hour, Amber, Peach, Rose, Lavender, Arctic, Ocean, Emerald, Pastel, Airy, Moody, Chrome, Retro Film, Silver, Charcoal and Warm Mono (32 entries including Original). Filter intensity defaults to 100%, supports 0–100% and is undoable; 0% leaves Adjust intact. Two-column thumbnails use the current geometry/AI snapshot and Adjust at the chosen intensity, without stacking the selected filter. They render only when Filter is open, at a longest edge of 160 pixels, and cache until geometry/Adjust/intensity changes. The shared Apply button appears to the right of Before in Filter, Adjust, Crop and Retouch modes. Crop and Retouch delegate to the existing panel Apply actions and their readiness checks. Adjust Apply stores the current look, including any pending filter, and resets pending controls to neutral; neutral Adjust is a no-op. In Filter mode: It commits the current filter and Adjust values as one ordered recipe, then resets pending controls to neutral so another filter can be stacked. Undo/Redo restores each applied recipe; Original clears only the pending filter, while Undo or Reset removes committed looks. No full-resolution bitmap is stored for filter layers. All photo rendering/export uses the same filter definition. AI Edit provides local LaMa object erasing and SD 1.5 masked text editing; see ai_edit_backend/README.md for installation, memory optimization and validation.

History contains up to 80 state snapshots, not full-resolution bitmaps. Geometry replays from the untouched original or the latest committed AI snapshot; subsequent geometry and adjustments still work. AI Apply bakes the current edit into a server PNG and adds exactly one history operation. Undo restores the preceding crop/adjust state; Redo reloads the AI snapshot if needed. Only one AI image is decoded in the snapshot cache at a time. A new edit after Undo removes the obsolete Redo branch. Reset is confirmed and undoable. At most 500 operations and 20 AI results per document; export/reopen to start a new document.

Wheel zooms around the pointer; drag pans outside Crop mode. Fit never magnifies small images, centre resets pan, clicking the zoom percentage sets 100%. Before is press-and-hold (pointer, Enter/Space on the button, or Space while the canvas is focused); release restores the previous zoom/pan and edited preview. A comparison slider is not included in this foundation.

Export creates a new JPEG, PNG or WebP blob. Current keeps edit dimensions; Original restores the original longest edge while retaining the edited aspect ratio, so cropped photos are never stretched. JPEG flattens transparency on white; PNG and WebP preserve alpha. Quality applies to JPEG/WebP. Automatic download and a persistent “Unduh salinan” fallback link use the same blob. The link is released on the next export/open. No original file is written or overwritten by the editor.

Editor history is session-only and separate from Upscale History. AI source, debug masks, preview and committed results use an isolated temporary folder, removed when the document is released or the server exits normally. Results have a 256 MB per-document limit and are never written over the original. Export before closing. Existing installed PyTorch, facexlib, OpenCV and restoration weights are reused; no new framework or automatic downloads.

## AI Retouch

Opening the page or a photo in another tool loads no Retouch models. Entering Retouch with a loaded photo, or loading a photo while Retouch is active, automatically detects up to 16 faces, obtains five landmarks, and creates semantic masks. There is no Analyze Face button. Valid analysis is reused on re-entry, including a no-face result. Committed edits invalidate analysis; it is refreshed automatically when Retouch is active. Failure/cancellation does not retry endlessly: use Coba lagi once processing has stopped, or leave and reopen Retouch. Detection does not modify the canvas. No face leaves the ordinary editor usable.

Skin Smooth defaults to 25, Blemish Removal 15, Face Restore 10 and Overall Strength 100. Preserve Skin Texture, Eyes, Hair and Identity default on. Auto Blemish defaults off because permanent skin marks cannot reliably be distinguished from temporary spots. The manual brush marks only skin pixels; other regions are excluded. Alis/bibir/hidung remain protected. Preserve Identity means conservative blending, not an identity guarantee.

Preview or a slider change after analysis renders a temporary preview; 220 ms debounce coalesces changes. Preview uses up to 1024 pixels on the longest edge (strength zero returns the exact source). Face masks and the expensive aligned restoration are cached per image revision. Crop, rotate, flip and other committed edits invalidate analysis. Apply processes full resolution and adds one history operation. Cancel discards only the temporary preview. Before still displays the original photo; export cancels any uncommitted preview first.

Backend model configuration and lifecycle are documented in `retouch_backend/README.md`. The UI uses a model-independent API. Mask debugging is development-only and disabled when the packaged runtime supplies `RONA_RESOURCE_DIR`.

Face scanning has a persistent status card near the device badge: gray without a photo, a spinner/progress during scanning, green when faces are found, yellow for no face/cancellation, and red for errors. Result notifications have a close button and dismiss after six seconds; the card remains visible. No-face results disable AI settings while other editor tools remain usable. Failed/cancelled scans expose Coba lagi after the current worker stops. Normal scans still start automatically. Node status tests cover scanning, success, no face, failure/retry and cancellation before inference; real browser verification also confirmed the no-face card and no console errors.

Below 900px the contextual panel becomes a toggleable drawer. Desktop remains the primary layout.

Adjust keeps Exposure, Brightness, Contrast and Saturation visible. A single closed-by-default Pengaturan lanjutan disclosure provides Whites, Blacks, Highlights, Shadows, Temperature, Tint, Vibrance, Sharpness and Vignette. Tone, color and vignette range from −100 to 100; Sharpness is 0–100. All default to zero. The tone/color operations run in one local pixel pass only when a nonzero advanced value is present. Whites/Blacks target extreme tones rather than the whole image. Sharpness uses a limited luminance difference against four neighbours, skips small differences and ignores transparent neighbours; a source copy is allocated only when sharpening is active. Vignette smoothly darkens edges for positive values and lightens them for negative values, preserving the center. All preserve alpha and run before the selected filter. Thumbnail, current render and export share the same processing; thumbnail spatial effects are approximate because of the smaller resolution. All 13 values participate in history and Netral kembali; closing a disclosure does not discard values. This is tonal/detail editing, not recovery of clipped detail or AI white balance. Web interaction/visual testing for these controls is left to the user.

## Validation

Run `node --test tests/retouch-engine.test.mjs` from the project root for history, crop boundary/ratio, fit and export sizing checks. Existing Python suite includes HTTP routes and authenticated Upscale upload/processing checks.

Open `/retouch/tests/verify.html` and click “Jalankan verifikasi” to run real browser canvas checks: pixel orientation, crop content, adjustments, AI snapshot history, Undo/Redo, original preservation, PNG/JPEG/WebP encode/decode and alpha/white matte. This isolated validation page makes no processing API calls and uses generated in-memory fixtures.

The audit folder records a real SwinIR CUDA HTTP smoke test, protected-file hashes and UI proof. Tests use isolated temporary data.

Cancel appears between Before and Apply in Filter, Adjust, Crop and Retouch. Filter/Adjust Cancel neutralizes only the active pending controls while preserving all applied look recipes and the other tool's controls; the cancellation is undoable. Crop/Retouch use their existing cancel actions, including AI job cancellation while busy. All Cancel buttons use a neutral transparent background with a rounded border. Advanced Adjust lists Vignette before Sharpness. Web interaction testing remains with the user.


## Adjust areas

The compact All / Person / Background selector above Exposure reuses the existing sliders. The first regional selection performs one offline DeepLabV3 MobileNetV3 person segmentation job through the Retouch service's existing GPU dispatch. It detects all people as one area, not separate individuals. The pinned 44,356,159-byte weight and SHA256 are recorded in `models/person-provenance.json`; loading uses `weights=None, weights_backbone=None` and never downloads during use. Inference is limited to a longest edge of 768 pixels; confidence/feathered masks are stored as lossless small PNGs in the edit recipe and projected through Crop, Rotate, Flip and Resize. Original alpha is retained. Fine hair and occlusion boundaries may need the optional brush correction.

All settings render first; Person and Background each adjust that same base, then complementary masks blend both results. Existing filters retain their order in the shared renderer. Preview, thumbnail, Apply and Export use the same mask/recipe path. Apply commits all pending adjustments as one look and neutralises the sliders; Cancel clears pending values; Undo/Redo retain masks. Saving to History includes masks so reopening does not scan again. Manual corrections create a new immutable mask so older applied layers are unchanged. Reset/new uploads clear the current area, and a new AI Retouch/AI Edit snapshot asks for new segmentation on the next regional selection. GPU model instances use the existing single-model cache and idle unload. Published EXEs are not updated by this source change.
